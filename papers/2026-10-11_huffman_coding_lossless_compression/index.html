Memory-Layout, Cache-Line Contention, and Bit-Exact Invariants in a Low-Level C Huffman Encoder/Decoder

Authored by Mateus Yonathan · Principal Investigator & Systems Engineer
Polyglot Systems Lab · Agentic Research Preprints · Vol. 2026

Abstract

Lossless Huffman coding remains a cornerstone of byte-wise compression in embedded and high-performance systems, yet its deterministic behavior on modern cache-centric CPUs is rarely examined at the source-code level. This work presents a self-contained C implementation that builds a frequency-ordered binary tree using an O(N²) priority queue, encodes symbols into a bit-packed stream, and reconstructs the original data without auxiliary metadata. Formal invariants guarantee prefix-freeness and bit-exact reversibility, while asymptotic analysis confirms linear-time encoding and decoding (O(|S|+||)) and O(||) auxiliary memory for the codebook. The implementation is verified through static abstract-syntax-tree inspection and formal proof rather than empirical timing.
